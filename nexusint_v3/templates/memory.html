How Memory Lab works
After each completed analysis module, SashaOps extracts 2–3 structural patterns (anonymised — no company names or figures) and stores them here. These patterns are then injected into future analyses so Gemini builds on prior findings rather than starting cold each time.

Tier 1 — client-specific insights, encrypted, visible only to that client.
Tier 2 — industry-level patterns, anonymised, shared within an industry group.
Tier 3 — cross-industry global patterns, extracted by the Pattern Learning engine below.
